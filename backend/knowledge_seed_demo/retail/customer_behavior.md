# 电商订单、售后与经营动作说明

客户数据只用于订单频次和购买结构分析，不引入会员体系。复购客户的定义是指定时间范围内订单数大于 1 的客户，复购率是复购客户数除以有订单客户数，必须先按 customer_id 聚合。

## 售后解释

售后记录包含“仅退款”和“退货退款”等类型，以及质量问题、物流破损、不喜欢、尺码不合适和拍错商品等原因。status = 已完成 才适合统计已完成退款金额；处理中记录可以作为待处理规模，但不能当作最终财务退款。

退款率要按退款金额计算，并与同期订单实付金额对齐。售后原因的占比只描述已登记售后，不代表全部未购买或潜在流失客户的原因。

## 可用的经营问题

Agent 可以分析哪些 SKU 毛利高但退款率也高、哪些省份物流慢且售后多、哪个渠道订单多但毛利低、哪些库存快照出现缺货，以及广告投放是否带来较高 ROAS。以上问题中的数值由 SQL 查询，规则和口径由知识检索补充。
