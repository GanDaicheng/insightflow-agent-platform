# 面试演示指南

## 一句话介绍

这是一个面向单个电商公司的经营分析 Agent。它能理解自然语言问题，拆解分析目标，选择问数和知识检索工具，观察返回证据，并生成带图表和来源说明的分析结果。

## 推荐演示顺序

1. 先问“分析 2025 年每月销售额、订单数和客单价趋势”，展示趋势图与指标口径。
2. 再问“找出销售额最高的 10 个 SKU，并比较它们的毛利率”，展示排行图和下钻思路。
3. 最后问“哪些省份销售额高但毛利率低，结合促销规则解释原因”，展示 Agent 连续调用数据工具和 RAG 工具。

## 面试官如何启动

面试官不需要下载原始数据。执行 README 中的 Demo 启动命令即可；初始化脚本会生成可重复的合成电商数据，并加载仓库内知识文档。

## 需要强调的边界

- PostgreSQL 提供会变化的事实数字，RAG 提供指标定义、业务规则和限制说明。
- Agent 不直接访问数据库，只能通过白名单工具查询。
- SQL 经过结构化生成、AST 校验、字段白名单和只读事务保护。
- 当前是本地演示原型，真实企业接入还需要身份认证、行级权限、Golden Dataset 和线上可观测性。
